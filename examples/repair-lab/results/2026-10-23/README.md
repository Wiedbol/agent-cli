# 真实对照结果：2026-10-23

本次完成十八次真实 DeepSeek 任务运行，**未观察到可归因于经验复用的收益或干扰**。两组成功率、请求数和工具数相同；token 和耗时有小幅波动。经验开关开启不代表建议实际命中。离线选择器重放另行记录，不能冒充实际网络请求抓取。

## 解释与限制

开启组token平均少141（约0.89%），耗时平均多0.338秒（约1.63%）。这些是本次观察值，不能声称节省成本或造成性能退化。模型采样、服务延迟等因素均未被独立控制，每格仅三次，且简单任务已有100%通过率。

运行器的控制台缓冲区含正常的 `token:` 状态行，触发现有整条内容脱敏，十八份控制台日志均被替换为过滤占位符。任务状态、验收证据、配置和指标仍保留，但实际网络请求中的建议注入没有独立日志。不能用原生任务的空建议ID列表推断外部评测适配器的注入情况。

使用同一选择器对归档用户消息离线重放，检查路径集合未改变、消息未脱敏及响应数与请求数一致；这只能重建确定性选择，不是网络抓取。十八次重放均未选中经验ID；消息无脱敏、路径集合稳定，重放响应数与各轮4次请求一致。结果见 [replayed-selection.json](replayed-selection.json)。原始候选适用范围很窄，因此本轮不足以回答“有效经验建议被注入后是否能帮助修复”。后续应先改进注入可观测性与匹配覆盖，在另获授权、重新冻结配置后进行新实验，不把本次结果改写成收益演示。
