# 可恢复、可验收并复用失败经验的 AI Coding Agent CLI

作者：高喜正，学号2601210313。

## 目标与技术主线

项目面向命令行中的真实代码修改任务，在已有Java17/Maven/DeepSeek工具调用循环上，增加两项能力：可靠继续一个有状态任务；从可核实修复中提炼并审核失败经验。自动修复提供业务场景，不能以模型说“完成”替代独立验收。

核心流程是用户约定目标与验收命令，控制员安排模型、守卫与执行员；工具边界前后保存检查点，记录调用身份、尝试次数、状态及版本；独立运行约定的Maven测试才能给出Verified。模型协议、命令执行、持久化及控制循环分开，离线替身与真实进程都能测试相同边界。

## 可靠继续执行

Task与Chat Session分别建模。续聊只恢复消息；`--resume-task`才继续任务，累计额度不会清零。已完成工具保留操作ID与结果，结果未知的命令暂停等待人工处置，不承诺任意指令恰好一次执行。工作区版本发生人工变化时，恢复暂停，用户审阅当前文件并明确重新规划；旧成功不能证明新现场正确，也不覆盖人工改动。

`replace_text`要求唯一原文及预期SHA-256，写入前显示Diff；编码与换行保持在编辑契约内。验收保护pom、测试和相关配置，缺失、空跑、过期、失败、超时、裁剪或不可解析的证据不能变成通过。读取任务状态成功不代表该任务已完成。

## 失败经验的来源与使用

提炼需要初始真实失败、Agent对应修复调用、完整文件版本链及有效最终验收。来源中混入无法归因的人工修改时拒绝提炼，不把人的修复算作Agent能力。模型只生成适用条件、错误特征、建议和限制；用户看完后明确保存，`--yes`或管道输入不能代替。

启用且同项目、来源可用的经验按确定性规则筛选，最多三条并去重；引用来源与匹配原因，仍须独立验收。禁用、失效、无匹配时正常继续。完整64位文件版本条件需与快照核对，不能当作错误日志里的普通词；本次演示发现并修复了这一具体漏匹配，不放宽版本不符的条件。

[十八次真实对照](../examples/repair-lab/results/2026-10-23/README.md)的运行代码为8cc801e，开启/关闭经验各9次，全数通过，平均均4次请求及4.56次工具；正式token283227。相同场景初始文件摘要一致，来源、试跑与提炼单列，无挑选最好结果或暗中重试。

当时原始候选范围窄，选择器事后重放零命中；控制台整体脱敏也限制了实际注入追溯。不能据此声称经验有收益，少量token/耗时波动不作因果解释。本次演示使用独立夹具、中文业务错误消息和后续版本条件修复，不回改历史评测，也不能拿同一缺陷的重现替代跨任务泛化证据。

[九分钟脚本](SCRIPT.md)串起失败、Diff、工具边界、人工冲突与重新规划、来源审核和新验收。备份是有真实时间戳的终端HTML，不是桌面视频；现场切换时必须说明是录制。实际审批/构建等待保留，可跳转或倍速，不能把历史输出叫现场结果。实际录制的任务、请求、命中与验收状态以本目录最终证据索引为准。

## 验证与边界

验证分三层：离线单元/集成回归；使用打包JAR、本地HTTP替身的兼容性检查；用户明确批准的真实DeepSeek演示。打包检查覆盖本地模式、UTF-8/GBK、续聊、显式导出、守卫及超时后代进程终止。真实演示不强迫模型首次写错，命令失败、预算暂停和未命中都保留。

回归曾发现Windows进程退出通知先于输出句柄释放导致清理失败；采用短暂、有上限的清理重试，保留原执行结果与中断语义，并重复验证跟踪失败边界。最终测试数量、录制版本和校验结果见演示交付README，不能用旧次数代替当前证据。

路径与风险检查不是操作系统沙箱；测试通过不是全面正确，脱敏不能保证识别任意秘密。当前不支持跨根迁移恢复、任意中断位置自动回滚或模型服务版本锁定。下一步应单独完善注入审计、更多真实失败场景与版本条件表达，再重新冻结实验验证收益。
